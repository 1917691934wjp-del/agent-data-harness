# 历史会话与上下文恢复

启动前在项目根目录运行一次：

```powershell
.\.venv\Scripts\python.exe scripts/setup_history.py
```

脚本初始化管理员账号（默认 `admin`）和签名密钥，不会覆盖现有账号。
新安装会提示输入密码并显示一次性恢复码；使用自己设置的密码登录。
已有 `.env` 账号会导入哈希账号库，保留原密码与用户名；登录后请清空旧环境密码。
`CHAINLIT_AUTH_SECRET` 用于签署登录会话，不是登录密码，重启时保持不变。

启动页面：

```powershell
.\.venv\Scripts\python.exe -m chainlit run src/data_agent/ui/app.py --host 127.0.0.1 --port 8000
```

登录后，左侧历史栏可以浏览、搜索、打开和删除会话。
第一条问题会作为默认标题。新建聊天创建独立上下文。
点击历史会话时，会恢复原业务范围、消息、SQL、表格、图表及 Agent 检查点。
如果上次停在查询计划确认界面，可继续输入“确认”“取消”或修改意见。
历史消息暂不支持原地编辑，以免屏幕记录与已经执行的 Agent 状态不一致。

## 本地文件

默认数据目录为项目根目录下的 `local_history/`，已经加入 Git 忽略规则。

- `chats.sqlite`：用户、会话元数据、消息、执行步骤、反馈，以及图表和表格附件。
- `accounts.sqlite`：独立账号、密码哈希、恢复码摘要、会话版本与数据源权限。
- `checkpoints.sqlite`：LangGraph 对话上下文、查询结果和待确认计划。

可通过 `DATA_AGENT_HISTORY_DIR` 指定其他目录。备份时先停止服务，再复制整个目录；
不要只复制其中一个数据库。删除会话会同时删除对应消息、附件和检查点。
此目录与只读业务示例数据分开，不会改动 `scripts/data/`。

现已支持多用户注册和账号管理。历史、附件及 Agent 状态按会话作者隔离；
新注册账号默认无业务数据源权限，须由管理员授权。详见 [多用户使用说明](MULTI_USER.md)。
对外部署需配置 HTTPS 和正确的 WebSocket 来源。

## 上下文范围

历史记录完整保存在磁盘，但模型每次调用仍按现有逻辑只读取最近若干条消息，
并结合当前查询状态工作；这不代表模型会自动检索所有旧会话。
不同会话的上下文彼此隔离，暂不提供跨会话长期记忆。

功能启用之前、只存在于内存的旧会话无法从磁盘恢复。
浏览历史不需要调用模型；继续提问仍需要有效的模型 API 配置。
